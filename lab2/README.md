### Синхронное межсервисное взаимодействие
Разработать информационную систему, которая будет организовывать хранение работ, присланных студентами, а также формировать отчет по каждой работе по результатам проверки на заимствования (антиплагиат).
### Архитектура
Проект состоит из трех микросервисов:
1. API Gateway - отвечает за routing запросов.
2. File Storing Service - отвечает за хранение и выдачу файлов.
3. File Analysis Service - отвечает за проведение анализа, хранение результатов, за предоставление результатов.
P.S.: Для каждого микросервиса создан свой Dockerfile. Также имеется docker-compose.yml -- главный "конейнерный" файл для запуска всего проекта.
### Базы данных
Используется PostgreSQL
* File Storing Service:
    *  База данных содержит id, filename, filepath файлов
    *  Сами файлы сохраняются в локальное хранилище
* File Analysis Service:
    *  База данных содержит id, filepath, результаты анализа

__Логика проверки работ на плагиат__

*Каждый сервис отвечает за какую-то конкретную работу*

1. **API** принимает все запросы от пользователей и распределяет запросы к нужным сервисам; собирает ответы от сервисов. (Например, принимает загружаемый в систему файл для проверки на плагиат, отправляет файл в File Storing Service, после получает id загруженной работы, связывается с File Analysis Service, предлоставляет id работы и тот, в свою очередь, ужу анализирует файл).
2. А сам **File Storing Service**, как уже выше написала, сохраняет загруженные файлы, записывет в базу данных данные даннные, прикрепленные к файлу.
3. **File Analysis Service** берет работы из File Storing Service, проверяет уже на плагиат, выводит отчеты(сюда же отнесем создание облачков слов).
4. В файле `plagiarism_checker.py` был создан специальный класс - `class PlagiarismChecker`, который содержит разные функции - загружаемый файл приводится к единообразию - удаляются пробелы, знаки пунктуации, буквы приводятся к нижнему регистру, вычисляется схожесть, составляется отпечаток текста. Также я добавила тестовые строки для прогона, они находятся в этом же файле - `plagiarism_checker.py`, можно запустить этот файл отдельно(не всем проектом), тогда будет видно, какой процент схожести у этих фраз(добавила фразы про кошку).
5. Далее текст анализируется на схожесть (текст разбивается на блоки по 50 слов, вычисляются хэши).
6. Потом через `SequenceMatcher` сравнивается текствовая схожесть исходных текстов: сравниваются две последовательности (слова), находится наибольшая общая подпоследовательность и возвращается процент схожести (в коде условилось, что если процент > 0.8 (то есть > 80%), то выводится сообщение о подозрении в плагиате).
7. Базы данных, для чего нужны, уже выше описала.
8.
